# Image Annotator

Qt6 と QML を使用して作成された、シンプルで使いやすい画像アノテーション（注釈）ツールです。

## 📁 含まれているバッチファイルの使い方

開発や配布を行うために、用途に合わせて以下のバッチファイルを実行してください。

### 🛠️ 1. 開発・動作確認用
- **`build_windows.bat`**
  - アプリのコンパイル（開発用ビルド）を行います。
  - プログラム（コード）を書き換えた後は、まずこれを実行してください。
- **`exec.bat`**
  - ビルドしたアプリを起動して動作確認を行います。
  - 開発中の `build` フォルダ内のアプリは単体でダブルクリックしても起動しないため、必ずこのバッチから起動してください。
- **`static_analysis.bat`**
  - C++ の Cppcheck と QML の qmllint を実行します。GitHub Actions と同じ対象ファイル・解析オプションで、push 前に静的解析の結果を確認できます（使用する Qt のバージョンはローカル設定に従います）。
  - qmllint は `--bare` で実行し、警告・エラーは残したまま説明用のソース抜粋などを省いて出力を簡潔にします。
  - 解析結果はリポジトリ直下の `static_analysis.log` に保存されます。ターミナルには完了状態とログの保存先が表示されます。
  - Cppcheck が見つからない場合は winget で自動インストールします。winget が必要です。Qt の `qmllint` は別途必要です。
  - Qt を `C:\Qt\6.11.2\mingw_64` 以外にインストールしている場合は、実行前に `QT_DIR` 環境変数を設定してください。
- **`run_tests.bat`**
  - CMake でテスト用ビルドを構成し、C++ の `tst_clipboardhelper`（QTest）と QML の `tst_qml`（Qt Quick Test / QQuickTest）をビルドして、CTest 経由で実行します。
  - テスト結果は失敗時に詳細が表示され、テストが失敗するとエラー終了します。
  - Qt、CMake、Ninja、MinGW は `C:\Qt\6.11.2\mingw_64` および `C:\Qt\Tools` 以下にインストールされていることを前提とします。
- **`clean.bat`**
  - ビルド時に発生した中間ファイル（キャッシュ等）を一括で削除し、容量を空けます。
  - （実行に必要な `.exe` ファイルは消えずに残ります）

GitHub Actions では `static-analysis` が C++ と QML の静的解析を行い、`unit-tests` が CMake で C++ の QTest と QML の Qt Quick Test（QQuickTest）をビルドし、CTest 経由で実行します。

### 📦 2. 他のPCへの配布用
- **`package.bat`**
  - 他のPC（Qtが入っていないWindows）でも動く「完成品パッケージ」を作成します。
  - 実行すると **`ImageAnnotator_Release`** というフォルダが作成され、中にアプリ本体(`appImageAnnotator.exe`)と必要なDLL群がすべて自動で集められます。
  - **配布方法:** この `ImageAnnotator_Release` フォルダをまるごとZIPファイルに圧縮して相手に渡してください。相手はフォルダ内の `.exe` をダブルクリックするだけでアプリを利用できます。
- GitHub にタグを push すると、GitHub Actions が Windows 用 Release ビルドを作成し、実行ファイルと必要な Qt ファイルを含む ZIP を GitHub Release に添付します。

## 💡 アプリの主な機能
- **画像の読み込みと切り替え**
  - 新規スクリーンショットボタンから画面を切り取り、撮影した画像を読み込めます
  - ドラッグ＆ドロップ、またはクリップボードからの貼り付け(Ctrl+V)に対応
  - 同じフォルダ内の画像を矢印キー(←/→)で簡単に切り替え
- **多様なアノテーション（図形）の描画**
  - 円（オーバル）、四角形、矢印、テキスト入力に対応
  - 描画後に円・四角形を選択し、塗りつぶしの適用・解除が可能
  - 描画時に **Shiftキー** を押すことで、正円・正方形・45度単位の矢印にスナップ
- **強力な「描画後の再編集」機能**
  - 👆（選択ツール）で描画済みの図形をクリックして選択
  - 選択中の図形を `R` キーで複製（元の図形から10pxずらして配置）
  - `Shift` キーを押しながら図形をクリックして複数選択し、まとめて移動・サイズ変更・色や線の太さの変更・削除
  - 図形のドラッグ移動
  - 四隅や両端に表示される**青いハンドル**を掴んで、サイズや向きを再調整（Shiftキーでのスナップ維持も可能）
  - 描画後でも、線の太さ・色・テキスト内容を自由に変更可能
  - 矢印キーでのオブジェクト微調整（Shift押下で10px移動）
- **操作の取り消しとやり直し**
  - Undo / Redo (Ctrl+Z / Ctrl+Y)
  - 選択図形の削除 (Delete) / 全クリア
- **画像の出力と共有**
  - アノテーション付きの画像を保存 (Ctrl+S)
  - アノテーション付きの画像をそのままクリップボードへコピー (Ctrl+C)

## ⌨️ ショートカットキー
- `V`: 選択ツール
- `C`: 円ツール
- `S`: 四角形ツール
- `T`: テキストツール
- `A`: 矢印ツール
- `F`: 選択中の円・四角形の塗りつぶしを切り替え
- `R`: 選択図形を複製（10pxずらして配置）
- `Ctrl+Z` / `Ctrl+Y`: Undo / Redo
- `Delete`: 選択図形を削除
- `Ctrl+S`: 名前を付けて保存
- `Ctrl+C` / `Ctrl+V`: 注釈画像のコピー / 画像の貼り付け

※`F`の塗りつぶし切り替えは、テキスト編集中には無効です。
